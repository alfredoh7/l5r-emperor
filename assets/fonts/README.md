# Game typography

- Headings: Musashi Brush, supplied by the user in musashi-brush(1).zip. Original font bytes preserved. The included terms restrict this copy to personal use; obtain the appropriate license before commercial or promotional distribution. Terms are retained beside the runtime font and in the exported resource pack.
- Body copy, rules, buttons, and resource numbers: Alegreya, normal variable font (default regular weight), downloaded from https://github.com/google/fonts/tree/main/ofl/alegreya on 2026-09-07. SIL Open Font License retained beside the runtime font and in the exported resource pack.

Both fonts are bundled; the game no longer depends on macOS system font availability. Runtime oversampling follows window density. Original card scans retain their printed type.
