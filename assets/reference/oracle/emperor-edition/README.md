# Optional Emperor research scans

The full-set source scans in `images/` are excluded from Git to keep the development checkout manageable. All runtime artwork and the selected Lion/Crane source scans are committed elsewhere; this archive is not needed to play, build or run the normal test suite.

Download `L5R-Emperor-Research-Images.zip` from the private **v0.3.10** GitHub Release if you need to research additional cards. Verify it against the release's `SHA256SUMS.txt`, then extract the ZIP at the repository root. It restores `assets/reference/oracle/emperor-edition/images/`; it does not replace the game implementation. The search records, receipts and content manifests in Git preserve the source context.

The archive contains reference card scans, not additional implemented cards. Preserve printing provenance when proposing new playable content.
