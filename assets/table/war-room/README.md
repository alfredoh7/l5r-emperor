# Candlelit command chamber — review milestones

Alfredo approved `approved-command-chamber.png` on 15 September 2026. This task builds the supporting table and room architecture in Blender, preserving the approved Topaz cloth and lacquer frame. The first review milestone covers proportions, composition, structural silhouettes and preliminary lighting.

Milestone 2 now integrates the room into the functioning board. Detailed props and final material/lighting fidelity remain later passes. Pause for Alfredo’s feedback at each milestone. No Meshy submission was made in this architecture pass. Related issue: #233 / draft PR #234.

## User steering during milestone 1

- Use the connected Meshy API for individual furnishings/props to retain their aged look. The cabinets here establish placement; their final geometry, textures and patina come through the prop pipeline. Do not treat the geometric placeholders as approved final art.
- The first room felt claustrophobic. The revision widens the room to approximately 4.3 m and moves the rear wall back. Main-room depth is 4.35 m, plus a 1.1 m vestibule. Table size remains 1.8 × 1.013 m. The preview lens widens from 34 mm to 30.5 mm to show the extra space; live camera settings are untouched.
- Arrange furnishings using the reference and judgement: armour/storage on the left, scroll/storage on the right, low perimeter work surfaces for map/tea and scrolls. Detailed prop anchors are named empties in the Blender file.

## Milestone 2 — live board and camera

Alfredo approved proceeding after the larger-room review. The default game in this task checkout now uses `WarRoomStage`, a native perspective scene around the existing card canvas. Use `Play Latest.command` (or the local app generated by `tools/create-dev-launcher.py`) to play this checkout. `--without-war-room` remains a diagnostic comparison with the previous environment; it is not a new player setting. The PR remains draft for milestone feedback.

The physical cloth is 1.8 × 1.013 m. Its logical extent is still calculated by `TableArtStage.EnvironmentExtent`, preserving the existing fabric clearance and board sizing. The room camera exactly reproduces `TableSurface`'s .64 pitch and .00065 depth projection using an off-axis frustum centered on the board viewport. No changes to `Main.Camera.cs`, card input, game state, rules or layout were needed. Lantern bases use the existing gutter calculation. Original mat/frame art, their proportions and the upright weathered lantern cutouts are reused. The lantern bodies remain cutouts until the Meshy object pass.

Static room geometry is combined into nine material batches at load time, down from 1,326 individually rendered mesh instances. The Blender source and placement anchors remain editable and separate. Preliminary fill/ambient lighting is softened from the architecture review; table and room candlelight freeze under reduced motion.
