# Emperor table prototype

Generated by `tools/blender/build_table.py`, executed through the project's pinned Blender MCP server in its dedicated scene. Safe mode remains enabled. The script uses Blender operators and the allowed math/JSON modules, with no network access or external asset imports inside Blender.

- `emperor-table.blend`: editable meshes, materials, packed textures, lights and review camera.
- `../../src/L5R.Client/Art/table.glb`: portable game asset with embedded images, standard PBR materials, no external file references.
- `table-review.png`: Blender review render, not a screenshot of gameplay.
- `walnut-grain.png` and `silk-weave.png`: deterministic procedural microtextures, also embedded in the deliverables.

The overall table measures 12 × 8 world units. Blender uses Z-up; glTF export converts to Godot Y-up. The playing silk spans 10.95 × 6.95 units. Ornament stays near the frame, apart from a subdued five-ring rosette.

Godot's `TableView` loads the GLB, supplies real-time lighting and an orthographic camera, and fits the table on viewport resize. `ApplyDirection(0/1/2)` changes the cloth and ink colors for the provisional green-silk, paper, and indigo directions. Game cards and controls remain independent native UI.

Rebuild from the repository root:

```sh
mkdir -p assets/table src/L5R.Client/Art
.tools/blender-venv/bin/python tools/blender/mcp_call.py run tools/blender/build_table.py
```

The Blender source embeds the current workspace root because MCP executes source inside Blender rather than as a filesystem script. Update the `ROOT` literal if the repository is moved. The script refuses to replace an unrelated scene.
