# 2026-10-17 unopposed gate and Battle/Open phase choice (pre-registration, non-inferiority)

- Issue / branch / arm: #1007, `claude/1007-bot-arena-gates`, arm `pre-gates` (`UseUnopposedGate = false, UsePhaseChoice = false`).
- Champion: `main` at d8277532 (both flags **on**, merged as #997, #998, #1003).
- **Direction.** Unlike earlier rounds the change under test is already the champion, so the arm is the *old* bot: `pre-gates` is the **challenger** and the champion is the new bot. A win rate
  for the challenger above 50% means the new behaviour is worse. All numbers below are quoted for the **new bot** (champion = 100% minus the challenger's rate) so the reading is the same as in the report.
- **Hypothesis (Mendon).** The three changes (no actions in unopposed battles except Force, Province-strength cuts, moves and Honor; no do-nothing Battle/Open uses; combat-only effects held for the
  Combat Segment) do not raise the win rate much, **but do not lower it.** They remove wasted actions and player time, not strength.
- **Expected effect:** the new bot's win rate 50% +/- 2 points; no per-deck collapse; fewer actions per game (the action counts in the report) and no more turn-limit games.
- **Decisive test:** mode `dev`, pairing `same`, `L5R_TOURN_SEED_START=100`, `L5R_TOURN_SEEDS=12` (fresh block; 864 pairs, 1,728 games), challenger `pre-gates`. Fixed sample, no extension.
  Primary metric: the new bot's win rate over decided games with its Wilson interval, and the paired result (pairs the new bot won both games versus lost both).
- **Decision rule (non-inferiority, in one sentence):** "no harm" if the new bot's win rate is at least 48% **and** the old bot does not win more pairs than the new bot at one-sided exact sign
  p < 0.10 **and** the new bot has no more bot stalls or other soundness findings than the old bot **and** no deck (>= 40 decided games piloted) where the new bot is below 35% while the old bot is at 50% or more.
  A significant win rate **above** 50% for the new bot is reported as an improvement but is not the expectation. Anything else is recorded as harm or inconclusive and the flags are reported to Mendon
  (nothing is reverted automatically).
- **Confirmation:** none planned; if the dev run shows harm or is inconclusive, a `holdout` run is a new pre-registration.
- **Wall clock / tokens:** about 30 to 40 minutes on this 16-core PC (about 15 worker threads); no model tokens per game.
- Notes: `same` pairing makes the two games of a pair identical except for the bot, so only games the changes touch can differ. The earlier #963 `reactions` run changed the outcome of only 34 of 864 pairs;
  the same limit applies here, which is why the paired counts are reported next to the win rate.

## Result (fill in after the single run; do not edit the plan above)

- Command: `L5R_TOURN_CHAL=pre-gates L5R_TOURN_PAIRING=same L5R_TOURN_MODE=dev L5R_TOURN_SEED_START=100 L5R_TOURN_SEEDS=12` (1,728 games). Report: `2026-10-17-gates-report.md`. Wall clock **1:20:33** on this
  16-core PC (0.36 games/s, 40 s per game on one core; the 30-40 minute estimate used the Mac's 0.9 games/s and was wrong for this machine). Tokens: none per game.
- **Outcome: no harm.** Numbers (decided 1,718 of 1,728):
  - **New bot (champion) won 865, old bot won 853 = 50.3%** (Wilson 95% interval 48.0-52.7%), above the registered 48% floor. Exact two-sided sign test p = 0.79.
  - **Paired:** new won both games of a pair 39 times, old won both 32 (783 pairs split); McNemar two-sided p = 0.48. The old bot did not win more pairs, so the one-sided harm test (p < 0.10) is not met.
  - **Soundness:** bot stalls 0, illegal commands 0, exceptions 0, decision-cap 0, setup failures 0. Ten games ended without a winner at the per-game wall budget (turns 24-32); all ten are Crab Control
    matchups (against Phoenix Talons 4, Scottish Lion 3, Crane preset 2, Crane Dominance 1), the slowest decks, on a machine running 15 games at once. A game belongs to both bots, so these cannot
    be assigned to either; they are recorded as informational, not a bot finding.
  - **Per deck (win rate piloting the deck, old to new):** Crab Control 37 to 37, Crane Dominance 51 to 54, Crane preset 58 to 60, Dragon Destruction 65 to 68, Lion preset 36 to 34, Phoenix Talons 26 to 22,
    Scorpion Lethargy 74 to 72, Scottish Lion 31 to 31, Spider Conquer 68 to 73. The lowest new-bot rate (Phoenix Talons 22%) is on a deck where the old bot is also well below 50%, so the collapse rule is not triggered.
  - **Margins and length:** provinces left +0.02, Honor +0.1, Personalities in play +0.05 (challenger minus champion); mean turn 14.5, no turn-limit games.
  - **What changed in play:** 145.4 actions per game for the old bot, 145.2 for the new; ability uses fall from 29.3 to 28.5 per game and passes rise from 54.6 to 55.5. The changes remove under one wasted
    ability use per game. That fits the expectation: no measurable strength change, less wasted play.
- Decision: the flags `UseUnopposedGate` and `UsePhaseChoice` stay on. No confirmation run was planned or is needed for a non-inferiority result.
