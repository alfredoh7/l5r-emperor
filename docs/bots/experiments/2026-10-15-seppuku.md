# 2026-10-15 seppuku (pre-registration, round 1)

- Issue / branch / arm: #963, `claude/963-bot-seppuku`, arm `seppuku` (`BotContext.UseSeppukuPolicy`, default off).
- Champion: `main` at the commit this branch started from (plus the unmerged instrument of #966).
- **Hypothesis.** The champion scores `orderSeppuku` with the "no rule" default (just above a pass), so it orders Seppuku whenever a Dishonorable Personality is offered. In the A/A the losing seat ordered
  it 2.3 times per game and the winner 0.3. Seppuku throws away a Personality to avoid only the Honor lost if it dies dishonored (its Personal Honor), and a Dishonored Personality is rehonored by
  winning a battle. So ordering it freely is wrong and should cost Personalities and games.
- **Change (Mendon's spec, no card or deck named).** Order Seppuku only for a Dishonored Personality, only if family Honor <= -5, only if dying dishonored would leave Honor <= -12 (within reach of the -20
  loss), and not if the Personality is part of the attack the bot plans this turn (winning it rehonors). Then weighed: `10 + 8 x Personal Honor + 3 x (-12 - Honor after its death) - 6 x Force` must beat a pass.
  Reads only the seat's own PlayerView and printed card data.
- **Expected effect:** +1 to +2 points of win rate against the champion, overall; no particular deck. Neutral where Seppuku is rarely offered. Small by construction: it only matters in games where a Personality
  is dishonored.
- **Why the paired design is primary.** The change alters play only in a minority of games. With `same` pairing both games of a pair share deck, seat order and shuffle, so a pair that never reaches a Seppuku
  decision is identical and uninformative, and only games the change actually altered can be discordant. Independent pairing would need about 4,900 decided games for a 2-point effect; the paired test needs
  as many games as there are discordant pairs. The `same` A/A is exactly deterministic (0 discordant in 71), which is what makes this valid. The independent-pairing win rate is not run for this round.
- **Decisive test.** Mode `dev`, pairing `same`, seeds 12-23 (`L5R_TOURN_SEED_START=12 L5R_TOURN_SEEDS=12`; fresh block, not used by any A/A) = 864 pairs, 1,728 games, about 32 minutes.
  Primary metric: pairs in which the challenger won both games vs lost both games (exact one-sided sign test, challenger better, **p < 0.025**).
  Also required: challenger win rate over decided games >= 51%; zero bot stalls and no more of any other soundness finding than the champion; no deck (>= 40 decided games piloted) where the challenger is
  below 35% while the champion is at 50% or more in the same run's pairing; mean provinces-left and Honor margins not negative. Stopping rule: fixed sample, no extension.
- **Confirmation (only if the dev test passes):** mode `holdout`, pairing `same`, seeds 3-12 (`L5R_TOURN_SEED_START=3 L5R_TOURN_SEEDS=10` = 600 games); rule: one-sided p < 0.10, win rate >= 50%, zero bot stalls.
- **Decision rule in one sentence:** promote-candidate only if the dev test and the confirmation both pass; anything else is recorded as negative or inconclusive and the flag stays off.

## Result (fill in after the single run; the plan above is not edited)

- Command: `L5R_TOURN_CHAL=seppuku L5R_TOURN_PAIRING=same L5R_TOURN_MODE=dev L5R_TOURN_SEED_START=12 L5R_TOURN_SEEDS=12` (1,728 games, 30 min wall clock). Report: `artifacts/bots/r1-seppuku-dev.md` (not committed).
- **Dev:** challenger 1002, champion 711 = **58.5%** (95% CI 56.1-60.8%); pairs won both 151, lost both 6 (exact one-sided p < 0.0001). 0 bot stalls; 15 engine stalls, all in the Crab Control / Dragon Destruction
  pairing (#967). Provinces-left margin +0.66, Personalities margin +1.17, **Honor margin -0.8**. Seppuku orders: champion 2,290, challenger 193. Every deck piloted by the challenger did as well or better than the
  champion's A/A rate. No deck collapse.
- **One registered secondary criterion was not met:** "Honor margin not negative" (-0.8). It was a poorly chosen criterion (military winners spend Honor); it is amended from round 3 on, not rewritten here.
- **Confirmation (holdout, seeds 3-12):** 1,200 games, not the 600 written above (10 seeds x 60 pairs x 2 seats). Challenger 645, champion 555 = **53.8%** (CI 50.9-56.6%), one-sided p = 0.005; pairs 48 vs 3; 0 stalls
  of any kind; Honor margin -0.6.
- **Outcome: promote-candidate** (primary test, win rate, soundness and confirmation pass; the Honor-margin criterion as written was not met and is flagged for the owner's decision).
