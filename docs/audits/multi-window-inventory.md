# Multi-window card inventory (issue #830)

Generated by `MultiWindowAuditTests` (generic kitchen-sink table, every ability probed in battle-attacker, battle-defender, action-active, action-other; offers are executed) plus per-card scenarios for abilities whose own preconditions the generic table cannot meet. Reaction windows are trigger-specific and are tracked separately below.

Window expectations: Battle = battle phase (attacker + defender); Open = Action phase, either player; Limited = Action phase, active player; BattleOrOpen = all four.
