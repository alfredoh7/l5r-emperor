# Fallen cards and dishonor presentation

Implements Alfredo’s approved A counter + B inspection panel for #21 and #221. PR #261 is stacked on the approved permanent-grants presentation #256, including UI consolidation #248. The separate Duel Demo #220 is excluded.

Each player’s existing three-stat placard has a separate Fallen strip underneath, using the approved counter frame and kabuto. Both the strip and clan medallion open that player’s Fallen gallery. Tabs inspect either player’s public pile; a scrollable list selects a full upright original card with an intact/broken fan and explicit death-status text. Back to table, close, or Escape dismiss it. Focus returns to the selected player’s counter. Long names wrap and reduce only as needed; full names remain available to tooltips/accessibility.

The strip and tabs read `PlayerView.DeadCount` directly. Gallery entries are only face-up, identified Personality cards in `Zone.Dead`. Ordinary Dynasty/Fate discards and Removed from the Game do not appear. Zero remains visible in the tracker; the gallery shows an empty state. Refreshing the public view removes stale selections when cards leave the pile. This screen never submits a game command or invents a cause, penalty, or return restriction.

In-play dishonorable Personalities turn 180 degrees, composed with bowing (270 degrees when also bowed). The complete printed face, stat inlays, projection and hit-testing share that transform. The quiet broken-fan medallion stays upright beside the card; token/grant rails and Force banners remain readable. Hover inspection faces and Fallen cards remain upright. Death status comes from the dead card’s public `Dishonorable` flag, including the engine’s existing Seppuku rehonoring before death.

## Review and reproduction

- Run `Play Latest.command` for this checkout. The local Mac app is generated by `python3 tools/create-dev-launcher.py`.
- Native checks: `bash tools/check-fallen.sh`.
- Core/content/AI/network checks: `bash tools/check.sh --skip-client`.
- Review `docs/screenshots/fallen/index.html` and `validation.md` for actual results and limits.
- `FallenProbe.tscn -- --interactive --mode=normal` provides a read-only native component review. Full-game capture modes begin `published-fallen` and only run with explicit `--capture`; fixture data is confined to the public presentation snapshot and never enters a playable deck or authoritative session.

The frames/icons use actual approved pixels; the intact large fan has a dedicated imagegen derivative. See `assets/ui/fallen/README.md` for crop geometry, preservation decisions and prompt provenance. Fonts remain Caudex/WeatheredQuill and original scans keep their full aspect ratios, so the rendered screen is not falsely described as pixel-identical to generated illustrative text/cards.
