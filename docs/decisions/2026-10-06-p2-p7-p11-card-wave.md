## Shared engine changes and compatibility

Core remains authoritative for prices, restrictions, targeting and negation. Existing choice contracts handle private looks, multi-target slots, signed Earth’s Protection amounts, province choices and forced discards. No new command or view field is introduced.

Resolved action facts feed P7 battle destruction records, preserving the originating action through Attack/Duel pauses. Counters are recorded only in matches containing the newly published consuming cards. Dynamic watch sequence is saved in MatchState; zero is omitted to preserve the serialized baseline of matches without dynamic watches. New definitions were previously unsupported; no existing published definition or ID mapping is changed. Compatibility and regression review remain in progress.

Tselu uses the existing mandatory targeting-trait continuation, before effects and Reactions; redirected targets are evaluated once per action. Earth’s Protection offers both bonus and penalty to a defender, only a bonus to the attacker, and creates linked watches for a single next bow-or-move negation.
