# Before the Dawn audit (issue #431)

Requested by Mendon on 2026-09-22: evaluate the 123 unwired Before the Dawn cards, wire what the engine's existing primitives (plus small, data-level generalizations) can reach, and document the blockers on what remains in `tools/content/build_card_inventory.py`'s `BLOCKERS` dict. Lane: rules.

**Result: 68 wired, 55 documented as blocked.** Waves: `personality-wave-43/45/46/47`, `strategy-wave-43/44`, `item-wave-8`, `spell-wave-16/17`, `follower-wave-20/21/22`, `holding-wave-6`, `celestial-wave-4`, `region-wave-5`. Tests: `btd-personalities`, `btd-cards`, `btd-creation`, `btd-gold-and-lock` (`tests/L5R.Core.Tests/BeforeTheDawn*.cs`), 39 tests total, mutation-tested (every surviving mutant of the new code either killed by a strengthened test or classified equivalent — none were).

## Readings and small generalizations, for Mendon to confirm or correct

1. **Kiuchi Chuda's "equalize"** (personality-wave-43): "Target your performing Personality and your performing Nonhuman or Undead Personality: set each Personality's Force equal to the higher printed Force of the two." Choosing the *same* card twice is refused by nothing special — the second slot's category (`own-nonhuman-or-undead-personality`) simply excludes a non-Nonhuman/Undead card, so a plain Personality can never be picked for both slots. No ruling needed; noted here only because the test exercises it.
2. **Doji Shigeyuki's duel**: "Both Personalities use their Personal Honor as their duel stat. Bow the duel's loser's unit" reuses the refusable-duel primitive (`IssuesDuel`, `DuelRefusable: true`, `DuelStat: "PersonalHonor"`) and the existing post-duel "bow the loser's unit" case shape (Shiba Kudome's). Straightforward; no reading needed.
3. **Moto Hailung's discount** ("4 less Gold while he is defending or you are a Crab Clan player"): read as **two mutually exclusive abilities sharing one use** (`hailung-attach` full price, `hailung-attach-discount` discounted), the same shape every other "X, or Y under a condition" card on this branch uses (Stockpiled Resources' Commander discount, Umiko's boost/reduce). Only one is ever offered.
4. **Asako Ebara's equip**: "a Weapon in your hand" is `AttachPile.OwnHand` — the primitive already built for Hailung and Ikoma Shinohara-shaped cards, generalized with no new code.
5. **Entry-window card-target listing**: an entering-play Reaction with a card target (Izuna's three keyword grants, Ashigaru Recruits' create) was never offered at all before this pass — the option showed "Choose a target to see this cost" with no candidate list. Added `AddTargetedEntryReaction` (`MatchQueries.cs`) alongside the existing target-less listing. This is an engine bug fix, not a rules reading, but it changes what every future entering-play targeted Reaction looks like in the client, so flagging it.
6. **Sly Deceiver's "permanently copies... but not those that copy abilities"**: read as the existing `PermanentlyCopyPersonality` primitive (Matsu Nimuro's), which already excludes an ability that itself copies abilities (`CopyableAbility`) and the three excluded keywords (Clan Champion, Daimyo, Shugenja) — Sly Deceiver's own exclusions match exactly, so no new code, only the wiring.
7. **The Crimson Mark's Focus Effect** ("you may destroy an attachment on a Personality involved in this duel"): generalized `FocusEffectChoice.cs`'s single hard-coded shape (Disreputable Deal's "take a Strategy from the discard pile") into a per-ability candidate list and per-ability action (take vs. destroy). No change to Disreputable Deal's own behavior.
8. **Kakita Yasunori's create**: "Remove a card in your Fate discard pile from the game **and** target your Personality" is two independent targets — read as a `Slots` ability (one slot with `Min 1, Max 1` for the discard-pile card, one for the host), the primitive built for issue #336's multi-target actions.
9. **Kakita Munemori - exp's phase-scoped lock** ("may not perform actions until the current phase ends"): generalized `ActionLock` with a `Phase:<instance>` duration string alongside the existing `Turn` one, stamped with the same phase-instance convention `PhaseLimits.Instance` already uses for once-per-phase limits. A lock of this kind lapses on its own when the phase (or the turn) changes, with nothing to clear.
10. **Necessary Evil's movement lock**: "may not assign to battlefields" is `MovementKinds.Assign` alone (the existing flags enum already separates Assign from Home/ToBattlefield) — the targeted Personality can still be moved by other effects, just not assigned in the Attack Phase's own assignment step.
11. **Necessary Evil's Gold cost** ("equal to the number of Personalities you control, or 4, whichever is higher"): a new `GoldCostBasis.OwnPersonalities` rule (`Modifier`/`Floor` reused, no target needed) — the first Gold-cost basis on a live count rather than a card's own printed or current stat.
12. **Yasuki Dokansuto's conditional production** ("When paying for a Holding, produce 2 Gold which may only pay for that card"): a new `ProductionCondition.PayingForHolding` case in the existing conditional-production primitive (Red Crane Dojo's Ninja discount, Bushi Dojo's Follower discount) — no new mechanism, one more condition.
13. **Goju Sawaki's Reaction** ("After another player's Battle action targets Sawaki, destroy him: create two Goju Genin"): the destruction is the Reaction's own cost (`CostVerbs.Sacrifice`), so the targeting action continues without him — nothing about it is negated. Confirmed by testing that the *action itself* (not just Sawaki) survives and applies its own effects to whatever else it named.
14. **Daigotsu Bukaro's create, on any Personality**: "target a Personality" (no "your") — the created Farmlands Conscripts follows the ordinary attachment-control rule (controlled by the host's controller), so Bukaro can arm an *enemy* Personality if the player chooses to. Tested explicitly, since it looks like a misprint at a glance.
15. **The Great Death's entry creation**: "Create three... Followers, attach them to it, **and** lose 6 Honor" is a trait (no Reaction: label), so it is mandatory and unconditional like `EntryHonorLoss` and Destined's draw — added to `ApplyMandatoryEntryEffects` rather than as an opt-in entering-play Reaction.

None of the above needed a new mechanism; each is a data-level generalization (new enum value, Effect string, category name, or a widened existing primitive) in the sense the team has been using on this branch.

## Cards not wired: cross-cutting gaps

The 55 blocker notes are in `tools/content/build_card_inventory.py`'s `BLOCKERS` dict (each keyed by its `oracle-l5r-<id>`), but the same handful of gaps recur across many of them — worth Mendon's attention as candidates for a future primitive pass, roughly by how many cards each would unblock:

- **"The cards/personalities an action affected" is not recorded** (5+ cards: Akodo Kobi, Hida Defenders, Measure of Devotion, Revenge, "was destroyed by another player's action" generally). Every negation and reaction reads the *currently held* action; nothing remembers what a *resolved* action did, so "after an action destroyed one of your X" triggers have no data to check against.
- **A trigger on assignment or movement of ANY Personality** (Utaku Tairu, Akodo Ashiko's recruit condition indirectly): the only after-move window that exists is scoped to Legion of the Bat's own narrow case (enemy Infantry moved to its own battlefield).
- **A Reaction that fires when an action is ANNOUNCED, before it resolves** (Ikoma Ayumu's Tactical straighten, Ikoma Shinohara's Tactical bonus): every existing "before/after an action" window is keyed to the action's *resolution*, never its announcement.
- **Additional-Action grants scoped by ability classification and/or a specific performer** (Mirumoto Inokuchi, Beyond the Line, The World of Wu — an existing gap this pass repeatedly rediscovers): `AdditionalActionGrant.ScopeCardIds` only ever names source cards.
- **A "was this card in play when the current Combat Segment/turn began" flag** (Headbutt, oracle-l5r-3010, and the earlier oracle-l5r-10335): no `EnteredPlayTurn`/`EnteredPlayBattle` field exists yet.
- **A one-shot effect that persists until consumed, across turn boundaries** (Drawing on the Mountain's "negate his next straightening this game", No Time for Games' delayed Honor-loss trigger): `StraightenBlockedTurn` and `NegatedEffects` both clear at fixed points, never "until used, however long that takes."

None of these is wired as part of this pass — building the primitive for any one of them is its own task, and several of the 55 cards would move once one lands.
