# Phase-order marker (#667)

Status: built from Mendon's confirmed ruling ("there are several cards that reorder phases ... look for other cases of unwired cards that perform this action. Validate which phases may be switched. Create a default order marker that triggers each phase. Then, when one of these actions is taken, change the marker so that the correct phase occurs. Create an animation that changes the location of the phases in the header and then resets them after the phases are completed"). The readings below are engineering readings for Mendon to confirm.

## Cards that reorder phases

A search of `content/deck-pool.json` (text patterns: "comes before/after", "option to create", "before the ... Phase", "instead of the ... Phase", "skip") found exactly two cards that reorder the turn's phases. Both are wired (strategy-wave-116):

| Card | Id | Status |
| --- | --- | --- |
| The Deciding Moment (Promotional-Emperor) | oracle-l5r-10119 | wired (Limited reorder + Battle draw), was blocked LOCK |
| Nocturnal Attack (Torn Asunder) | oracle-l5r-10385 | wired (the "Ninja action" Mendon remembered); was unwired and unblocked |

Not the same primitive (left alone): Aramasu's Legacy, Hofukushu's Vengeance, Retribution, The Perfect Moment, Two Fronts and Twist of Fate create or add phases/actions without changing the order; "skip" effects are out of scope.

## The marker

`MatchState.PhaseOrder` (`src/L5R.Core/PhaseOrder.cs`, property order 1600): `Order` (the six printed phases by name in the order the turn runs), `Begun` (printed phases begun this turn), `ChangedTurn`. The default is `Straighten, Events, Action, Attack, Dynasty, End`. The three hard-wired transitions now ask the marker: end of the Action Phase (`BeginPhaseAfterAction`), end of the Attack Phase (`BeginPhaseAfterAttack`, wired into the declined attack, the last battle, and the post-maneuvers path), end of the Dynasty Phase (`EndDynastyPhase`, wired into `endDynasty`, the pass, and the Twist of Fate window). With the default order every call makes the same `SetPhase`/`EndTurn` call as before.

- **Which phases may be switched** is data (`PhaseOrderRules.AllowedSwaps`): only Attack and Dynasty. Any other order is rejected. The marker can only be changed while neither phase it moves has begun this turn.
- **Reset**: the marker returns to the default as the End Phase begins (and again as the next Straighten Phase begins), so the next turn is always default.
- **View**: `MatchView.PhaseOrder` (string[], null while default) is public and identical for both seats.
- **Wave Man** ("After an Attack Phase ends: straighten"): was triggered by entering the Dynasty Phase; with the Dynasty Phase first it triggers as the Attack Phase ends, just before the turn ends.
- **Client**: `PhaseTrack` slides the phase names between the (fixed) medallion slots when `PhaseOrder` changes and slides them back when it returns to null; the lit slot and help follow the phase in each slot; reduced motion places the names at once. The phase-bar art itself is unchanged (the plate is a blank lacquer rail with native labels).
- **AI/bot**: the training opponent is driven by offered actions, not by phase assumptions; no change was needed.

## Readings built in (not confirmed rulings)

- **Five Rings in play** = the Enlightenment test applied to the other player: all five elemental Rings (Fire, Water, Air, Earth, Void; no False Ring, none stripped of Enlightenment) in play under his control. "Another player ... has five Rings" is not read as any five Ring cards.
- "Another player has 40 or more Honor" and "has five Rings" test the opponent; "you have -20 or lower" tests the user.
- Playing a second reorder when the order is already Dynasty first is allowed and changes nothing; neither card can restore the default order.
- Once the Dynasty Phase has begun (e.g. in Twist of Fate's additional action) or the Attack Phase has begun, a reorder is refused.
- With the Dynasty Phase first, the Attack Phase is still the optional declare-or-decline decision (Nocturnal Attack's printed "option to create an Attack Phase"); declining or finishing it ends the turn.
- A Limited action's own timing already restricts both cards to the Action Phase (Limited), so they are always played before either swapped phase.
- Nocturnal Attack's cost is bowing a performing, unbowed Ninja Personality at any location (an Action Phase action).
- The Deciding Moment's Battle half is a plain "draw a card" with no further condition, usable at a battle with a unit there as any Battle action.
