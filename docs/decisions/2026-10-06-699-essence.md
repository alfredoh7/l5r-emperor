## The ruling

"Probably easiest to, if the shugenja is void, run the province flip effect twice in succession. For the Void variant, if the first flip is negated, so is the second, and the second cannot be negated if the first was not. These may be any provinces (either player's). Province selection should be limited only to face down cards. The second flip is optional if it is available. If this is more complex than some other way of doing it, push back."

## How it is built

One action, `wl-read-the-essence-flip`, costs paid once (the Spell bows).

1. **First flip = the action's target.** The existing `any-province` command parameter (TargetPlayerId + Province), the same shape as Second City, Study the Wheel and Ring of Earth. Every client already lists those provinces, highlights them on hover and lets the player pick one. Validation limits it to a province that holds a FACE-DOWN card (either player's); a face-up, empty, destroyed or out-of-range province is refused with no state change. The effect turns the card face-up and a revealed Celestial enters play (core rules; as in Petty Squabbles).
2. **Second flip = the action's second step.** After the first flip, if this Shugenja is Void (read as the effect resolves, granted keywords included) and another face-down province card exists, a public `effectChoice` opens for the acting player (the engine-listed choice of `BeginListedEffectChoice`, answered by `chooseEffect`). One answer per other face-down card, named by province only ("Turn the card in your province 2 face-up", "...Name's province 3..."), plus "Do not turn a second card face-up". If no other face-down card exists nothing is offered. The province a Celestial was refilled into counts, because the answers are computed after the first flip.
3. **Negation.** A reaction that negates the action negates the whole action (ActionNegation.cs): no flip happens, the second is never offered, the bow cost stands. When the action was not negated, its negation window has closed before the second step, and the second answer runs with no window at all, so it cannot be negated. This is exactly "first negated => second negated; first not negated => second cannot be negated".
4. **Hidden information.** Offers and the pending choice name provinces, never the face-down card or its id.

## Pushback (the two choices Mendon may want to correct)

* **Not two commands.** Running the whole province-flip action twice would need the second to be a second action (a second window, a second negation chance, a second bow) and a "linked negation" between two separate resolutions. One action with a sequenced second step gives the linked negation for free and pays the cost once, so that is what is built. The first target is chosen with the action, and the second is chosen after the first card is face-up (so a Celestial entering play, or the refill it causes, can matter), the same way Engulfing Flames' second target is sequenced.
* **No simultaneous two-province selection (the #674 block).** Petty Squabbles' "one or two" set (hidden ids in CardIds) exists, but offering every pair would make the second choice blind to the first flip and would put a quadratic list of pairs in front of the player; the sequenced step has a clear optional "Skip" instead.

Reading to confirm: "the same province twice" cannot arise: a province holds one card, so the second flip is necessarily in another province.
