## What it is

`DuelRules` is a record on `PendingDuel.Rules` (null, and not saved, for an ordinary duel). The engine reads it where each rule applies, so what `QueryDuelActions` offers, what `ResolveDuelCommand` accepts and what `ResolveDuel` counts cannot disagree:

| Rule | Meaning | Read by |
|---|---|---|
| `ExcludeItemBonuses` | the duelists' attached Items add nothing to the duel stat (both sides) | `DuelStatValue` (subtracts `ExcludedItemDuelBonus`) |
| `MinFocusEach` | each side focuses at least N times if possible before a Strike | `DuelStrikeRefusal` (validation and the offered Strike) |
| `ExactFocusEach` | each side focuses exactly N times if possible: at N a side may not focus (nor use a stand-in), and a Strike waits as above | `Focus`, `DuelFocusSlotOpen`, `QueryDuelActions` |
| `FirstToFocusPlayerId` | that player, not the challenged player, has the first opportunity to focus or strike | `BeginFocusing` (`DuelFirstFocuser`) |
| `AutoLose` (`DuelAutoLoss(CardId, AgainstTitle?)`) | the card loses any duel against that title (or anyone) whatever the totals; both named, both lose | `ResolveDuel`, after the totals and tie-breaks, beside Daidoji Tametaka - exp's rule |
| `RefusalCost` (`DuelRefusalCosts.DishonorAndMoveHome` / `Bow`) | the challenged player pays this to refuse; a refusal whose cost cannot be paid is neither offered nor accepted; the offered label names the cost | `DuelRefusalOpen`, `ResolveDuelRefused` (`PayDuelRefusalCost`), `DuelPresentation` |
| `RefusableWhen` (`DuelRefusableConditions.*` or a card key) | the challenge is refusable only while the condition on the two Personalities holds when it is issued | `IssueChallenge` |

"If possible" means a side has met the count when it has focused that often **or can focus no more** (no card to focus from, at the four-focus cap, or its exact count reached). A Strike ends focusing for both sides, so it waits until both have met the count; the one exception, so that no position leaves neither a focus nor a Strike legal, is a player who himself has nothing left to focus with.

## The API the wave calls (module initializer, priority >= 10000, unique ids)

```csharp
// The same rules on every duel one ability issues:
DuelRuleRegistry.ForAbility("OtaniDuelRules", 12900, "otani-duel", new DuelRules { ExcludeItemBonuses = true });
// Rules that read the board (a null answer = none; several answers merge):
DuelRuleRegistry.Register("ShindoDuelRules", 12900, static c => c.Challenger.DefinitionId == Shindo ? new DuelRules { FirstToFocusPlayerId = c.ChallengerPlayerId } : null);
// A card's own RefusableWhen key (e.g. "an honorable target" is built in; anything else is a key you answer):
DuelRuleRegistry.RefusableWhen("MyKey", 12900, "my-condition", static c => c.Challenged.Bowed);
// The substitute duelist (Seppun Ryota's shape, Ezuno's redirect restricted to challenge-issuing actions); the card lists the ability on its definition:
DuelRuleRegistry.Substitute("RyotaSubstitute", 12900, "ryota-substitute", "Reaction: the challenge targets Ryota instead", affectedFilter: null, bowsReactor: false);
```

Merging: a flag is on if any answer says so, the larger minimum wins, the first named exact count, first player, refusal cost and condition win, auto-losses add up. `DuelRulesContext` carries `Engine`, `AbilityId`, `ChallengerPlayerId`, `Challenger`, `Challenged`, `Source`.

## Readings for Mendon to confirm or correct

- **R-027 holds for the counts.** Only real focuses (cards in `ChallengerFocused`/`ChallengedFocused`) count toward a minimum or an exact count; Kakita Gonji's and Reserve Weapon's "instead of focusing" stand-ins are not focuses. Under `ExactFocusEach` a side that has reached its count may not use a stand-in either (a stand-in takes the place of a focus).
- **Automatic loss overrides the tie-break.** `AutoLose` is applied after the totals and the Duelist tie-break, the way Daidoji Tametaka - exp's "loses any duel against Yoritomo Hiromi" already is, so a Duelist's tie win does not save the card. If both participants are named, both lose.
- **Refusal cost dishonor-and-move-home** needs the Personality in play and not already dishonorable; it is paid when he refuses, before the printed refusal consequences. It is a cost, not an effect: no watch or shield negates it. **Bow** needs him unbowed. (Fusako's "bow him to gain the right to refuse" is a different, existing mechanism and is unchanged.)
- **RefusableWhen is judged once, when the challenge is issued**, from the two Personalities then. A card's own key that nothing answers never opens a refusal.
- **The substitute duelist acts in the before-action window, before the challenge is answered.** R-014 (He's Mine!/Irezu act only in an accepted or mandatory duel) governs the before-duel-begins window and is untouched; the substitute is Ezuno's redirect (`RedirectAction`) and so also needs the substitute to be legal against the challenge (`ActionAcceptsTarget`), the same location as the Personality he stands in for, and another player's action.
- **First to focus** changes only who acts first; the alternation after the first focus is unchanged.
