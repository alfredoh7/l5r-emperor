# Claude Code project entrypoint

Read `AGENTS.md`, `AI_HANDOFF.md`, `docs/PROJECT_STATUS.md`, and `CONTRIBUTING.md` before making changes. Those files are the shared project instructions used by Codex and Claude Code; do not create a conflicting second architecture or status record here.

Use a `claude/<issue>-<topic>` branch and a separate worktree/clone when another session is working. Read the GitHub issue and recent PRs, reproduce the issue, record evidence, and update the handoff before yielding. The latest user instructions take precedence over repository guidance.
