# Weathered Quill headings

WeatheredQuill-Regular.ttf was supplied by Alfredo on 2026-09-09, alongside the equivalent OTF. The TTF is loaded by Godot FontFile as the shared UI heading font. Use uppercase UI headings and compact spacing (FontVariation SpacingGlyph = -1), per Alfredo’s follow-up after seeing the mixed-case version. Label font variations trim excess vertical line-box padding without altering glyph outlines. Menus fit the full line box and long turn labels fit the plaque width. Alegreya remains the reading/body font. Original card scans and the illustrated title logo are artwork, not re-typeset UI labels.

No font license was included with these files; this record identifies user-supplied provenance and does not assert a redistribution license.
